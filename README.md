# GE150 / GE150 Pro 프리셋 적용기

MOOER GE150 Pro, GE150 기타 멀티이펙터에 프리셋 200개를 한 번에 넣는 윈도우 프로그램입니다.
AI 가 만든 톤 JSON 이나 `.mo` 파일을 끌어다 놓으면 장비에 적용하고, 적용 전에 장비 전체를 자동으로 백업합니다.

## 지원 기종
| 기종 | 상태 |
|---|---|
| GE150 Pro | 실장비로 읽기·쓰기·백업 복원까지 확인했습니다. |
| GE150 | 공식 에디터 분석을 바탕으로 만들었고 **실장비로는 시험하지 못했습니다.** 처음에는 슬롯 한 개만 적용해 확인해 주십시오. |

연결한 장비의 기종은 프로그램이 자동으로 알아냅니다.

## 내려받기
이 저장소의 **Releases** 에서 `GE150PresetLoader.exe` 를 내려받아 실행합니다. 파이썬은 필요 없습니다.

## 쓰는 순서
1. **연결**: 장비를 PC 에 연결하고 전원을 켭니다. 케이블은 GE150 Pro 는 USB-C, GE150 은 USB Type-B(PC 연결용 단자)입니다. 공식 에디터가 켜져 있으면 닫습니다.
2. **실행**: `GE150PresetLoader.exe` 를 실행하면 장비를 읽어 200개 프리셋 목록을 보여 줍니다.
3. **AI 에게 요청**: 내 기종의 요청문(`GE150Pro_AI_프롬프트.txt` / `GE150_AI_프롬프트.txt`, 이 저장소의 [prompts](prompts) 폴더, 또는 Releases 의 `GE150Pro_AI_prompt.txt` / `GE150_AI_prompt.txt`)을 열어 `[곡 목록]`에 곡을 적고, 전체를 ChatGPT·Claude·Gemini 같은 AI 에게 붙여 넣습니다. 받은 JSON 은 `.json` 파일로 저장합니다.
4. **불러오기**: 저장한 `.json` 파일을 프로그램 창에 끌어다 놓습니다. 오류가 있으면 사유 목록이 나오므로 그대로 AI 에게 보내 고쳐 달라고 합니다.
5. **적용**: 표에서 바뀔 슬롯을 확인하고 **장비에 적용**을 누릅니다.

자세한 설명은 [사용법](docs/사용법.md), JSON 형식은 [톤 JSON 형식](docs/톤JSON_형식.md)에 있습니다.

## 백업과 되돌리기
적용 전에 장비 전체가 `백업` 폴더(exe 옆)에 자동 저장되고, 백업이 실패하면 아무것도 쓰지 않습니다. 쓴 뒤에는 장비를 다시 읽어 저장 여부를 확인하고, 어긋난 슬롯은 다시 씁니다.
되돌리려면 **백업에서 되돌리기**로 `백업\날짜-시간` 폴더를 고르고 **장비에 적용**을 누릅니다. 다른 기종의 백업은 거부됩니다.

## 소스로 실행
```
pip install -r requirements.txt
python app.py              # 창 실행 (장비 없이 연습: python app.py --fake  또는  --fake=ge150)
python -m pytest           # 시험 (pip install pytest 필요, 장비 없이 돕니다)
```
exe 만들기: `pip install pyinstaller` 후 `build.cmd`.

## 주의
- MOOER 와 관계없는 **비공식** 개인 도구입니다. 장비 통신은 공식 에디터의 동작을 분석해 만들었습니다.
- 장비의 프리셋을 덮어쓰는 프로그램입니다. 사용으로 생기는 문제(데이터 손실, 장비 오동작 등)는 사용자 책임이며 저작자는 책임지지 않습니다. 중요한 프리셋은 따로 보관해 두십시오.
