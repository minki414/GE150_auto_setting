# GE150 / GE150 Pro 프리셋 적용기

## 처음 오셨다면: 합주용 샘플 톤으로 초기 세팅하기

**합주 전에 아래 1~7단계만 순서대로 따라 해 주세요.** 이 페이지의 링크에서 필요한 파일을 모두 받을 수 있습니다. 코딩이나 파이썬 설치, AI에게 톤을 만들어 달라고 하는 작업은 필요 없습니다.
준비된 김마굴밴드 합주용 **50뱅크·200개 프리셋**을 장비에 넣는 과정입니다. 프리셋은 장비에 저장된 소리 한 칸이고, 이 샘플에서는 네 칸씩 묶어 한 뱅크로 부릅니다. Pro 본체와 적용기는 `01A`~`50D`, GE150 본체는 `P001`~`P200`으로 표시합니다.

### 1. 내 기종 확인 → MOOER 공식 에디터 받기

장비 본체에 적힌 모델명을 확인하고 **내 기종에 해당하는 한 줄만** 따라 하세요. `GE150`과 `GE150 Pro`는 서로 다른 모델입니다.

**공식 사이트 최신 배포 버전 확인일: 2026-11-17.** 아래는 MOOER 공식 에디터 다운로드 페이지입니다. 페이지를 연 뒤 표에 적힌 파일 이름 옆 **Download**를 누르세요.

| 내 장비 | MOOER 공식 다운로드 페이지 | 받을 파일: Windows / Mac | 확인한 최신 버전 |
|---|---|---|---|
| **GE150 Pro** | [GE150 Plus/Pro/Max 공식 다운로드](https://www.mooeraudio.com/Downloads_xq/6.html) | `GE150_Pro_V2.1.4_Win` / `GE150_Pro_V2.1.4_Mac` | **V2.1.4** |
| **GE150** | [GE150 공식 다운로드](https://www.mooeraudio.com/companyfile/GE150-Downloads-146.html) | `GE150_V1.3.8_Win` / `GE150_V1.3.8_Mac` | **V1.3.8** |

- **Windows PC와 Mac 모두 쓸 수 있습니다.** 내 컴퓨터에 맞는 `Win` 또는 `Mac` 파일을 받으세요. Mac에서 다르게 하는 부분은 각 단계의 **Mac** 표시를 보면 됩니다.
- Pro 다운로드 페이지에는 Plus·Max용 파일도 있습니다. **이름에 `GE150_Pro`가 들어간 파일**을 고르세요. GE150은 `V1.3.8_Win`을 고르면 됩니다.
- 공식 사이트가 나중에 갱신되면 파일 이름과 버전도 바뀔 수 있습니다. 그때는 같은 모델의 최신 `Win`(Mac은 `Mac`) 파일을 받으세요.

### 2. PC·케이블 준비 → 공식 에디터에서 연결 확인

준비물은 **Windows PC 또는 Mac, 장비와 전원 어댑터, 데이터 전송이 되는 USB 케이블, 기타와 기타 케이블, 소리를 확인할 헤드폰 또는 앰프**입니다. GE150 Pro 공식 소프트웨어의 Windows 요구 사항은 Windows 10 이상입니다. Mac에 USB-C 단자만 있다면 장비 케이블에 맞는 변환 어댑터나 USB-C 케이블을 준비하세요.

1. 1단계에서 받은 압축 파일을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택합니다. 풀린 폴더 안의 설치 프로그램(`.exe`)을 실행하고 화면 안내대로 설치합니다.
   - **Mac**: 받은 `.zip`을 더블클릭해 풀고, 안의 `.dmg`를 더블클릭합니다. 열린 창의 `GE150PRO.app`(GE150은 `GE150.app`)을 **응용 프로그램** 폴더로 끌어다 놓습니다.
2. 장비에 전원을 연결하고 평소처럼 켭니다. 스위치를 누른 채 켜는 업데이트 모드 대신, **일반 연주 화면**에서 시작하세요.
3. 장비와 PC를 USB로 연결합니다. 충전만 되는 케이블은 쓸 수 없습니다.

   | 내 장비 | PC 연결에 쓸 장비 쪽 단자 |
   |---|---|
   | GE150 Pro | **USB-C** |
   | GE150 | **USB Type-B**: 프린터에서 흔히 보는 네모난 단자. 작은 **마이크로 USB(OTG)** 단자는 스마트폰 녹음용이므로 여기서는 쓰지 않습니다. |

4. 설치한 **MOOER 공식 에디터**를 실행합니다. 내 장비의 프리셋 목록이 보이는지 확인합니다.
5. 확인했으면 **공식 에디터를 완전히 종료**합니다. 이후 사용할 프리셋 적용기와 동시에 켜 두면 USB 연결이 충돌합니다. **Mac**은 창만 닫으면 앱이 남아 있을 수 있으니, 에디터를 앞에 둔 채 `⌘ Command + Q`로 종료하세요.

**펌웨어 업데이트 안내가 나온다면:** 펌웨어는 장비 안에서 동작하는 소프트웨어입니다. 에디터 설치와 장비 펌웨어 업데이트는 별도 작업이며, 위 표의 버전은 공식 다운로드 패키지의 표기입니다. 업데이트가 필요한 경우 기존 톤을 먼저 공식 에디터로 백업하고, 위 공식 다운로드 페이지의 **내 모델용 업데이트 순서**를 따르세요. 업데이트 중에는 USB와 전원을 유지하고, 완료되어 일반 화면으로 다시 켜진 뒤 다음 단계로 넘어갑니다. 아래 적용기의 자동 백업은 **샘플 톤을 쓰기 직전**에 만들어지므로, 그보다 먼저 진행한 펌웨어 업데이트의 백업을 대신하지 않습니다.

### 3. 이 페이지에서 적용기와 내 기종의 샘플 받기

아래 **① 실행 파일 + ② 내 기종 샘플 한 개**를 받아 같은 폴더에 둡니다. 예를 들어 바탕 화면에 `GE150_합주세팅` 폴더를 만들면 됩니다.

| 받을 것 | 바로 내려받기 |
|---|---|
| ① 프리셋 적용기: 두 기종 공용 (**Windows**) | [GE150PresetLoader.exe](https://github.com/minki414/GE150_auto_setting/releases/download/v1.1.0/GE150PresetLoader.exe) |
| ① 프리셋 적용기: 두 기종 공용 (**Mac**) | [최신 릴리스](https://github.com/minki414/GE150_auto_setting/releases/latest)의 **Assets**에서 `GE150PresetLoader-mac-arm64.zip`(M1·M2 등 Apple 칩 Mac) 또는 `GE150PresetLoader-mac-x86_64.zip`(Intel Mac). 내 칩은 화면 왼쪽 위 Apple 메뉴 → **이 Mac에 관하여**의 **칩**(Apple M…) 또는 **프로세서**(Intel…)에서 확인합니다. |
| ② **GE150 Pro**를 쓴다면 이 샘플 | [band_sample_GE150Pro.json](https://github.com/minki414/GE150_auto_setting/releases/download/v1.1.0/band_sample_GE150Pro.json) |
| ② **GE150**을 쓴다면 이 샘플 | [band_sample_GE150.json](https://github.com/minki414/GE150_auto_setting/releases/download/v1.1.0/band_sample_GE150.json) |
| 합주곡과 뱅크 번호 확인용 | [50뱅크 목록 보기](samples/합주곡_목록.txt) · [목록 파일 내려받기](https://github.com/minki414/GE150_auto_setting/releases/download/v1.1.0/band_song_list.txt) |

위 링크는 샘플을 함께 배포한 **v1.1.0** 파일입니다. 파일을 따로 찾으려면 [릴리스 다운로드 화면](https://github.com/minki414/GE150_auto_setting/releases/tag/v1.1.0)의 **Assets**를 펼치면 됩니다. `Source code (zip)` 대신 위 이름의 파일을 받으세요.

**Mac에서 적용기 준비:** 받은 `.zip`을 더블클릭하면 `GE150PresetLoader.app`이 나옵니다. 이 앱은 Apple 개발자 인증서로 서명하지 않은 개인 도구라서, 처음 열 때 "확인되지 않은 개발자" 또는 "Apple에서 악성 코드가 없음을 확인할 수 없습니다" 경고가 나옵니다. 아래 순서로 한 번만 허용하면 다음부터는 그냥 열립니다.

1. `GE150PresetLoader.app`을 더블클릭하고, 경고 창에서 **완료**(또는 **취소**)를 누릅니다.
2. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽 **보안** 항목의 "GE150PresetLoader 사용이 차단되었습니다" 옆 **그래도 열기**를 누르고, 암호(또는 Touch ID)를 입력합니다.
3. 다시 뜨는 창에서 **열기**를 누릅니다. (macOS 14 이하에서는 앱을 Control 키를 누른 채 클릭 → **열기**로도 됩니다.)

**`.json`은 톤 설정이 들어 있는 파일입니다.** 내용을 복사하거나 직접 고칠 필요 없이, 내려받은 파일 그대로 사용합니다. 링크를 눌렀는데 다운로드 대신 글자가 가득한 화면이 열리면, 링크를 마우스 오른쪽 버튼으로 눌러 **다른 이름으로 링크 저장**을 선택하세요. 파일 이름 끝이 `.json`인지 확인합니다(`.json.txt`나 `.html`이면 안 됩니다).

저장소의 [합주_GE150Pro.json](samples/합주_GE150Pro.json) / [합주_GE150.json](samples/합주_GE150.json)과 위 영문 파일은 같은 샘플입니다. 저장소 파일 화면에서 받을 때는 오른쪽 위 **Download raw file** 버튼을 쓰면 됩니다.

### 4. 적용기 실행 → 내 장비 읽기

1. **공식 에디터가 닫혀 있고**, 장비의 전원과 USB가 연결되어 있는지 확인합니다.
2. 내려받은 `GE150PresetLoader.exe`를 더블클릭합니다. 이 파일은 별도 설치 없이 실행됩니다. **Mac**은 `GE150PresetLoader.app`을 더블클릭합니다.
3. 잠시 기다려 위쪽에 **`GE150 Pro 연결됨` 또는 `GE150 연결됨`**이 표시되는지 확인합니다. 표의 **지금 장비** 열에 현재 프리셋 이름 200개가 나타나면 정상입니다.
4. 연결이 안 되면 공식 에디터 종료와 USB 단자를 확인한 뒤 **장비 다시 읽기**를 누릅니다. 기종 표시가 내 본체와 맞는지 확인하고 다음으로 넘어가세요.

### 5. 내 샘플 불러오기 → 장비에 적용

**이 작업은 기존 프리셋 200칸(`01A`~`50D`)을 합주용 샘플로 바꿉니다.** 적용 직전에 기존 200칸이 자동 백업되고, 백업이 실패하면 쓰지 않습니다. 이미 소중한 톤이 있다면 공식 에디터로도 따로 보관해 두세요.

1. 적용기에서 **톤 JSON 불러오기**를 누릅니다.
2. 3단계에서 받은 **내 기종의 `.json` 파일**을 고르고 **열기**를 누릅니다. 파일을 적용기 창에 끌어다 놓아도 됩니다. **공식 에디터가 아닌 프리셋 적용기(`GE150PresetLoader`)에서 여는 파일**입니다.
3. 표의 **바꿀 톤** 열에 `Antifreeze CLN` 같은 이름이 채워지는지 확인합니다. `오류`가 나오면 적용을 진행하지 말고 아래 문제 해결 표를 확인하세요.

**GE150 사용자만: 먼저 한 칸 시험하기**

GE150용 샘플은 Pro 톤을 변환한 것이며, **GE150 실장비에서는 아직 시험하지 못했습니다.** 처음부터 200칸을 쓰기 전에 아래 확인을 먼저 해 주세요. GE150 Pro 사용자는 바로 다음 전체 적용 순서로 넘어갑니다.

1. **전체 해제**를 누른 뒤, 표의 **`01A` 행 맨 왼쪽 체크박스만** 선택합니다.
2. 오른쪽 아래 **바꿀 슬롯: 1개**를 확인하고 **장비에 적용**을 누릅니다. 확인 창에서 진행하고 결과를 기다립니다.
3. 결과가 완료인지 확인하고, GE150 본체의 **`P001`(적용기의 `01A`)**을 골라 이름과 소리를 확인합니다. 이름이 바뀌지 않거나 오류가 나면 전체 적용을 멈추고, 결과 창과 백업 폴더의 `결과.txt`를 보관해 저장소 작성자에게 전달해 주세요.

**두 기종 공통: 전체 적용하기**

1. **전체 선택**을 누릅니다. **바꿀 슬롯: 200개**인지 확인합니다.
2. **장비에 적용**을 누릅니다. 확인 창에서 덮어쓸 개수와 예상 시간을 확인한 뒤 진행합니다.
3. **백업 → 쓰기 → 저장 확인**이 끝날 때까지 기다립니다. 200개 쓰기는 약 80초이고, 백업·확인·재시도 시간이 더 들 수 있습니다. 진행 중에는 장비 조작, USB 분리, 전원 끄기를 피하세요.
4. 결과 창 첫 줄이 **`결과: 쓰기 완료 / 기록 저장 완료`**이고, 아래에 **`완료 200개`**가 나오는지 확인합니다. 실패·미확인·저장 안 됨이 있으면 아직 초기 세팅이 끝난 상태가 아닙니다. 결과 창의 안내를 따르세요.
5. 실행 파일 옆에 생긴 **`백업` 폴더를 그대로 보관**합니다. 샘플에서 변환된 톤 폴더도 같은 작업 폴더에 만들어지므로, 처음에는 폴더째 보관하면 편합니다. **Mac**에서는 백업이 **문서 → `GE150PresetLoader` → `백업`** 폴더에 만들어집니다(처음 백업할 때 "문서 폴더에 접근하려고 합니다" 창이 나오면 **허용**을 누르세요). 변환된 톤 폴더는 `.json` 파일이 있는 폴더에 생깁니다.

### 6. 장비에서 소리와 저장 상태 확인하기

1. 적용이 끝난 뒤 적용기를 닫고 USB를 분리합니다. 장비 전원을 껐다 켭니다.
2. 기타를 장비의 **INPUT**에, 헤드폰을 **헤드폰 단자(PHONES / 헤드폰 그림)**에 연결합니다. 앰프로 확인한다면 평소 쓰는 출력 연결을 사용합니다. USB 연결은 앞 단계에서 설정을 전송하는 데 사용했으며, 여기서는 장비의 출력에서 소리를 듣습니다.
3. 기타 볼륨을 열고, 장비와 앰프·헤드폰의 출력 음량은 작게 시작해 천천히 올립니다. EXP 페달이 볼륨으로 설정되어 있다면 앞쪽을 내려 볼륨이 열리는지도 확인합니다.
4. 본체의 **PLAY** 버튼을 눌러 연주 화면으로 돌아갑니다. Pro는 **SELECT** 노브, GE150은 **VALUE** 노브를 돌려 아래 프리셋을 고릅니다. **전원을 다시 켠 뒤에도 이름과 소리가 남아 있는지** 확인합니다.

   | 적용기 / Pro 본체 번호 | GE150 본체 번호 | 들어 있어야 할 이름 | 쓰임 |
   |---|---|---|---|
   | `01A` | `P001` | `Antifreeze CLN` | 클린: 깨끗한 반주 |
   | `01B` | `P002` | `Antifreeze CRN` | 크런치: 살짝 거친 반주 |
   | `01C` | `P003` | `Antifreeze DRV` | 드라이브: 강한 록 반주 |
   | `01D` | `P004` | Pro: `Antifreeze SOLO` / GE150: `Antifreeze SOL` | 솔로: 멜로디·리드 연주 |

이 샘플은 **같은 번호의 A·B·C·D가 같은 곡**입니다. 예를 들어 `01`은 검정치마의 Antifreeze, `02`는 EVERYTHING입니다. GE150에서는 첫 곡이 `P001`~`P004`, 두 번째 곡이 `P005`~`P008` 순으로 네 칸씩 이어집니다. [전체 목록](samples/합주곡_목록.txt)에서 이번 합주곡의 번호와 영문 이름을 찾아 해당 곡의 네 가지 톤을 미리 연주해 보세요. GE150은 Pro 전용 효과를 비슷한 효과로 바꾼 버전이라 Pro와 소리가 다를 수 있습니다.

본체 조작을 더 확인하려면 [MOOER GE150 Pro 제품·설명서 페이지](https://www.mooeraudio.com/products/207.html) 또는 [GE150 제품·설명서 페이지](https://www.mooeraudio.com/product/GE150-228.html)의 **Download**에서 설명서를 받을 수 있습니다.

이 과정에서 넣는 것은 곡별 프리셋입니다. 전체 출력 음량, 페달 보정 같은 장비 공통 설정과 외부 IR·앰프 샘플 파일을 설치하는 작업은 포함하지 않습니다. 기타·헤드폰·합주실 앰프에 따라 들리는 소리와 적정 음량도 달라지므로, 합주 때 쓸 연결에서 한 번 더 맞춰 주세요.

### 7. 합주 오기 전 마지막 확인

- [ ] 내 기종의 샘플로 **200개 적용 완료**를 확인했다.
- [ ] 전원을 껐다 켠 뒤에도 `01A`~`01D`(GE150 본체: `P001`~`P004`)의 이름과 소리가 남아 있다.
- [ ] [곡 목록](samples/합주곡_목록.txt)에서 이번 합주곡의 뱅크 번호를 찾고, 필요한 톤으로 바꾸는 연습을 했다.
- [ ] 기타를 직접 연결해 소리와 볼륨을 확인했다.
- [ ] PC의 `GE150_합주세팅` 폴더와 그 안의 `백업` 폴더를 보관했다(Mac: 문서 → `GE150PresetLoader` → `백업`).
- [ ] 장비, 전원 어댑터, 기타, 필요한 케이블을 챙겼다.

### 막히면 여기부터 확인하세요

| 증상 | 확인할 것 |
|---|---|
| 장비를 찾을 수 없음 | 전원 → 데이터 전송용 USB 케이블 → 올바른 단자(Pro: USB-C / GE150: Type-B) → 공식 에디터 종료 순으로 확인하고 **장비 다시 읽기**를 누릅니다. USB 허브를 쓰고 있다면 PC에 직접 연결해 보세요. |

| 샘플을 열 때 오류 | 연결된 기종과 파일 이름이 맞는지 확인합니다. GE150에는 `band_sample_GE150.json`, Pro에는 `band_sample_GE150Pro.json`입니다. 파일을 다시 내려받고 확장자도 확인하세요. |
| 쓰기 실패·미확인·저장 안 됨 | 결과 창과 `결과.txt`를 확인합니다. 연결을 바로잡고 **장비 다시 읽기**로 현재 상태를 확인한 뒤 안내에 따라 다시 적용합니다. |
| 이름은 바뀌었는데 소리가 안 남 | 기타의 INPUT 연결, 헤드폰·앰프 연결, 기타 볼륨, 장비 출력 음량, EXP 볼륨을 차례로 확인합니다. |

## 프로그램 소개

MOOER GE150 Pro, GE150 기타 멀티이펙터에 프리셋 200개를 한 번에 넣는 Windows·Mac 프로그램입니다.
AI 가 만든 톤 JSON 이나 `.mo` 파일을 끌어다 놓으면 장비에 적용하고, 적용 전에 장비 전체를 자동으로 백업합니다.

### 지원 기종

| 기종 | 상태 |
|---|---|
| GE150 Pro | 실장비로 읽기·쓰기·백업 복원까지 확인했습니다. |
| GE150 | 공식 에디터 분석을 바탕으로 만들었고 **실장비로는 시험하지 못했습니다.** 처음에는 슬롯 한 개만 적용해 확인해 주십시오. |

연결한 장비의 기종은 프로그램이 자동으로 알아냅니다.

### 내려받기

이 저장소의 [Releases](https://github.com/minki414/GE150_auto_setting/releases)에서 내려받아 실행합니다. 파이썬은 필요 없습니다.

| 컴퓨터 | 받을 파일 |
|---|---|
| Windows 10 이상 | `GE150PresetLoader.exe` |
| Mac (Apple 칩: M1·M2·M3…) | `GE150PresetLoader-mac-arm64.zip` → 풀어서 `GE150PresetLoader.app` |
| Mac (Intel 칩) | `GE150PresetLoader-mac-x86_64.zip` → 풀어서 `GE150PresetLoader.app` |

Mac에서 처음 열 때의 보안 경고는 위 3단계의 **Mac에서 적용기 준비**를 따르세요.

### 샘플 톤으로 바로 시작

김마굴밴드 합주곡 50곡(200개 프리셋)의 톤 세트를 [samples](samples) 폴더에 넣어 두었습니다.

- [GE150 Pro 용](samples/합주_GE150Pro.json) — 실제 장비에서 읽은 값
- [GE150 용](samples/합주_GE150.json) — 위 파일을 자동 변환한 것(소리가 Pro 와 다를 수 있습니다. [변환 내역](samples/GE150_변환내역.txt))

내 기종의 `.json` 을 프로그램 창에 끌어다 놓고 **전체 선택 → 장비에 적용**을 누르면 우리 밴드 세팅이 그대로 들어갑니다. 자세한 내용은 [samples/README.md](samples/README.md)입니다.
GE150은 위 초기 세팅 안내처럼 슬롯 한 개를 먼저 시험한 뒤 전체 적용해 주세요.

### 쓰는 순서

샘플을 쓰려면 3·4단계 대신 샘플 JSON 을 끌어다 놓으면 됩니다.

1. **연결**: 장비를 PC 에 연결하고 전원을 켭니다. 케이블은 GE150 Pro 는 USB-C, GE150 은 USB Type-B(PC 연결용 단자)입니다. 공식 에디터가 켜져 있으면 닫습니다.
2. **실행**: `GE150PresetLoader.exe`(Mac: `GE150PresetLoader.app`)를 실행하면 장비를 읽어 200개 프리셋 목록을 보여 줍니다.
3. **AI 에게 요청**: 내 기종의 요청문(`GE150Pro_AI_프롬프트.txt` / `GE150_AI_프롬프트.txt`, 이 저장소의 [prompts](prompts) 폴더, 또는 Releases 의 `GE150Pro_AI_prompt.txt` / `GE150_AI_prompt.txt`)을 열어 `[곡 목록]`에 곡을 적고, 전체를 ChatGPT·Claude·Gemini 같은 AI 에게 붙여 넣습니다. 받은 JSON 은 `.json` 파일로 저장합니다.
4. **불러오기**: 저장한 `.json` 파일을 프로그램 창에 끌어다 놓습니다. 오류가 있으면 사유 목록이 나오므로 그대로 AI 에게 보내 고쳐 달라고 합니다.
5. **적용**: 표에서 바뀔 슬롯을 확인하고 **장비에 적용**을 누릅니다.

자세한 설명은 [사용법](docs/사용법.md), JSON 형식은 [톤 JSON 형식](docs/톤JSON_형식.md)에 있습니다.

### 백업과 되돌리기

적용 전에 장비 전체가 `백업` 폴더(Windows: exe 옆, Mac: 문서 → `GE150PresetLoader` → `백업`)에 자동 저장되고, 백업이 실패하면 아무것도 쓰지 않습니다. 쓴 뒤에는 장비를 다시 읽어 저장 여부를 확인하고, 어긋난 슬롯은 다시 씁니다.
되돌리려면 **백업에서 되돌리기**로 `백업\날짜-시간` 폴더를 고르고 **장비에 적용**을 누릅니다. 다른 기종의 백업은 거부됩니다.

### 소스로 실행

```
pip install -r requirements.txt
python app.py              # 창 실행 (장비 없이 연습: python app.py --fake  또는  --fake=ge150)
python -m pytest           # 시험 (pip install pytest 필요, 장비 없이 돕니다)
```
Windows·Mac 모두 같은 명령입니다(Mac은 `python3`).

- Windows exe 만들기: `.venv`에 `pip install pyinstaller` 후 `build.cmd` → `dist\GE150PresetLoader.exe`
- Mac 앱 만들기: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt pyinstaller` 후 `./build_mac.sh` → `dist/GE150PresetLoader.app`과 배포용 `dist/GE150PresetLoader-mac-<칩>.zip`. 빌드한 Mac의 칩용으로만 만들어집니다.
- GitHub Actions(`.github/workflows/build.yml`)가 Windows·Mac(Apple 칩·Intel)에서 시험을 돌리고 세 파일을 모두 만듭니다. `v`로 시작하는 태그(예: `v1.2.0`)를 올리면 그 릴리스에 세 파일이 자동으로 올라갑니다.

### 주의

- MOOER 와 관계없는 **비공식** 개인 도구입니다. 장비 통신은 공식 에디터의 동작을 분석해 만들었습니다.
- 장비의 프리셋을 덮어쓰는 프로그램입니다. 사용으로 생기는 문제(데이터 손실, 장비 오동작 등)는 사용자 책임이며 저작자는 책임지지 않습니다. 중요한 프리셋은 따로 보관해 두십시오.
