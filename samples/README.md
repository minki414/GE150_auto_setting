# 샘플 톤

김마굴밴드 합주곡 50곡(1곡 = 1뱅크 = A CLEAN · B CRUNCH · C DRIVE · D SOLO, 슬롯 01A~50D 200개)의 톤 세트입니다. 장비를 처음 쓸 때 초기 세팅으로 바로 넣을 수 있습니다.

| 파일 | 내용 |
|---|---|
| `합주_GE150Pro.json` | GE150 Pro 용 톤 JSON. 실제 장비에서 읽어 낸 값입니다(2026-11-12 기준). |
| `합주_GE150.json` | GE150 용 톤 JSON. 위 파일을 자동 변환한 것입니다. |
| `GE150_변환내역.txt` | GE150 판으로 바꾸며 달라진 내용(종류별 건수와 슬롯별 목록). |
| `합주곡_목록.txt` | 50곡 목록. 줄 끝 괄호는 장비에 표시되는 이름의 앞부분입니다. |

## 쓰는 법
1. 프로그램을 실행해 장비를 읽습니다.
2. 내 기종에 맞는 `.json` 파일을 프로그램 창에 끌어다 놓습니다.
3. 표에서 **전체 선택**을 누른 뒤 **장비에 적용**을 누릅니다. 장비의 200개 프리셋이 이 세트로 바뀝니다. 적용 전에 장비 전체가 자동으로 백업되므로 **백업에서 되돌리기**로 원래대로 돌릴 수 있습니다.

## 알아 둘 점
- GE150 판은 자동 변환입니다. GE150 에 없는 Pro 전용 모델(예: S-COMP, SHIMMER)을 가장 비슷한 모델로 바꾸고 노브 값을 근사했으므로 **소리가 Pro 판과 다를 수 있습니다.** 대응 모델이 없는 옥타브 등은 꺼진 상태로 들어갑니다. 자세한 내용은 `GE150_변환내역.txt` 에 있습니다.
- GE150 은 실장비로 시험하지 못한 기종입니다. 처음에는 슬롯 한 개만 적용해 확인해 주십시오.
- 곡을 바꾸고 싶으면 저장소의 `prompts` 폴더에 있는 요청문에 내 곡 목록을 적어 AI 에게 톤을 받으십시오.
- 내 장비의 현재 상태를 이런 파일로 저장하려면 프로그램의 **장비→톤 JSON 저장**을 쓰십시오.
