# GE150 / GE150 Pro 프리셋 적용기 사용법

미리 준비한 톤 데이터(`.mo` 파일)나 AI 가 만든 톤 JSON 을 MOOER GE150 Pro 또는 GE150 장비에 한 번에 넣는 프로그램입니다.
연결한 장비가 어느 기종인지는 프로그램이 자동으로 알아냅니다.

- **GE150 Pro**: 실장비에서 확인했습니다.
- **GE150**: 공식 에디터 분석을 바탕으로 만들었고 **실장비로는 시험하지 못했습니다.** 처음에는 슬롯 한 개만 적용해 확인해 주십시오(화면에도 같은 안내가 나옵니다).

## 1. 실행 전 준비
1. 장비를 노트북에 연결하고 전원을 켭니다.
   - GE150 Pro: USB-C 케이블
   - GE150: USB Type-B 케이블(PC 연결용 단자). 마이크로 USB(OTG) 단자는 스마트폰 녹음 전용이라 연결에 쓰지 않습니다.
2. **공식 에디터가 켜져 있으면 닫습니다.** USB를 동시에 쓰면 충돌합니다. 프로그램은 GE150 Pro 에디터(`GE150PRO.exe`)가 켜져 있으면 연결하지 않고 닫아 달라고 안내합니다. GE150 용 에디터는 자동으로 검사하지 않으므로 직접 닫아 주십시오.
3. `GE150PresetLoader.exe`를 더블클릭합니다. 파이썬 설치는 필요 없습니다.

## 2. 화면 순서
1. 시작하면 장비를 찾아 200개 프리셋을 읽어 표의 **지금 장비** 열을 채웁니다(약 3초). 위쪽에 `● GE150 Pro 연결됨` 또는 `● GE150 연결됨`이 보이면 정상입니다.
2. **폴더 선택**을 눌러 톤 데이터(`.mo`)가 들어 있는 폴더를 고릅니다.
   - 파일 이름 앞 3글자가 적용될 슬롯입니다. 예: `13A Buzz CLN.mo` → 13A 슬롯. (`01A`~`50D`, 대소문자 무관)
   - 폴더에 있는 파일에 해당하는 슬롯만 바뀝니다. 13A 파일 하나만 있으면 13A 한 칸만 바뀝니다.
   - 앞 3글자가 슬롯 형식이 아닌 파일은 표 맨 아래에 **슬롯 미지정**으로 나옵니다. 슬롯 칸에서 원하는 슬롯을 고르면 표에 반영됩니다.
3. 표의 **상태**를 확인합니다.
   - **변경**: 장비 내용과 달라서 바뀔 슬롯입니다(처음부터 체크되어 있습니다).
   - **동일**: 장비 내용과 같습니다.
   - **파일 없음**: 폴더에 해당 파일이 없어 건드리지 않습니다.
   - **백업 복원**: 백업 폴더의 원본 값으로 되돌릴 슬롯입니다(3절).
   - **오류**: 적용할 수 없습니다(파일 형식 오류, 값 범위 초과, 이름이 길이 제한 초과(GE150 Pro 16자, GE150 14자)·허용 안 되는 문자, 같은 슬롯 파일 2개). **경고** 열의 사유를 확인합니다. 체크할 수 없습니다.
   - **경고**(적용은 가능): 사용자 샘플 칸(GE150 Pro 는 AMP·CAB, GE150 은 CAB)을 쓰는 톤입니다. 장비에 샘플이 설치되어 있지 않으면 의도와 다른 소리가 납니다.
4. 필요하면 **변경된 것만 선택 / 전체 선택 / 전체 해제**로 체크를 조정합니다. 오른쪽 아래에 바꿀 슬롯 수가 표시됩니다.
5. **장비에 적용**을 누르고 확인 창에서 진행합니다.
   - 적용 직전에 공식 에디터가 켜져 있는지 다시 확인합니다(켜져 있거나 확인할 수 없으면 적용하지 않습니다).
   - 먼저 장비 전체 200개를 `백업\날짜-시간\` 폴더에 자동 백업합니다. **백업이 실패하면 아무것도 쓰지 않습니다.**
   - 확인 창에 **예상 시간**(슬롯 1개당 약 0.4초, 200개 약 80초)이 나옵니다. 장비가 응답만 하고 저장하지 않는 일이 있어(실장비 시험에서 확인), 슬롯마다 응답 뒤 0.3초씩 쉬면서 차례로 씁니다. 진행 표시는 "쓰는 중 → 저장 확인 중 → 다시 쓰는 중(1/2)" 순서입니다.
   - 다 쓰면 장비를 다시 읽어 **모든 선택 슬롯은 목표와, 선택하지 않은 슬롯은 원본과** 대조합니다(재읽기마다 전부 다시 검사). 목표와 다른 선택 슬롯은 **자동으로 다시 씁니다**(1.0초 간격, 최대 2회). 선택하지 않은 슬롯이 원본과 달라지면 다시 쓰지 않고 "예상 밖 변경(관측 회차 n)"으로 보고하며 실패로 판정합니다(성공한 모든 재읽기에서 대조하므로, 중간에 달라졌다가 마지막에 원래대로 돌아와도 기록이 남습니다). 다시 쓴 횟수(예외가 난 쓰기도 한 번으로 셉니다)와 최종 상태는 결과 창과 `결과.txt`에 나옵니다. **중단**은 다시 쓰는 단계에서도 지켜지고, 중단하거나 USB 오류가 난 뒤에는 추가로 쓰지 않고 읽기만 한 번 시도합니다. 재읽기가 한 번이라도 실패하면(다시 읽어 성공해도) 그 적용에서는 더 쓰지 않고, "읽기 오류가 있어 다시 쓰기를 멈췄습니다. 같은 폴더로 다시 적용하십시오."라고 안내합니다.
   - **중단**을 누르면 지금 쓰는 슬롯까지만 마치고 멈춥니다. 적용 중에 창을 닫으려 하면 "지금 슬롯까지 마치고 멈춘 뒤 닫습니다"라고 확인한 뒤 같은 방식으로 멈추고 닫힙니다.
   - 슬롯 상태는 **마지막으로 성공한 전체 재읽기**로만 정합니다. **완료** = 그 재읽기에서 목표와 일치 / **저장 안 됨** = 그 재읽기 이후 쓰기가 없었는데 목표와 다름 / **미확인** = 그 재읽기 이후 쓰기를 보냈거나 재읽기를 한 번도 성공하지 못함(결과에 "마지막 확인 시점: n회차 재읽기" 또는 "확인 못 함"이 적힙니다) / **실패(응답 없음)**·**미시도**. 모든 선택 슬롯이 완료이고 예상 밖 변경이 없고 `결과.txt` 저장도 성공했을 때만 전체가 성공입니다. 미확인 슬롯은 장비에 들어갔는지 알 수 없으므로 장비를 다시 읽어 확인하십시오.
   - 끝나면 결과 창 첫 줄에 **쓰기** 결과(완료/중단/실패)와 **기록**(결과.txt 저장) 결과가 따로 나오고, 슬롯별 개수·백업 위치가 이어서 나옵니다. 같은 내용이 백업 폴더의 `결과.txt`에도 남습니다. `결과.txt` 저장에 실패하면 같은 내용을 `%LOCALAPPDATA%\GE150PresetLoader\결과-시각.txt`에 한 번 더 저장하고 그 위치를 결과 창에 보여 줍니다.
   - 적용 중에 창을 닫아도 작업이 끝나면 결과 창을 먼저 보여 준 뒤 닫힙니다.
   - 백업의 성공 기준은 원본 `device.bin`과 `backup.json`이 저장·검증되는 것입니다. 장비의 어떤 슬롯을 읽어 해석하지 못하거나 `.mo` 파일을 쓰지 못해도(파일 이름에 못 쓰는 문자는 `_`로 바꿔 저장하고, 같은 이름이 겹치면 번호를 붙입니다) 백업과 쓰기는 멈추지 않고, `.mo`가 빠진 슬롯은 `결과.txt`에 경고로 남습니다.

## 3. 되돌리기
- **백업에서 되돌리기**를 누르고 `백업\날짜-시간` 폴더를 고르면, 그 폴더가 톤 데이터 폴더로 지정됩니다. 이 프로그램이 만든 백업 폴더에는 장비 원본 데이터(`device.bin`)와 확인용 파일(`backup.json`)이 들어 있습니다. `backup.json`과 `device.bin`이 서로 맞으면 표의 상태가 **백업 복원**으로 표시되고 원본 그대로(값 검사 없이) 장비에 다시 씁니다. 파일이 손상되었거나 서로 맞지 않으면 "백업 손상" 안내와 함께 그 폴더 전체를 거부하고 아무것도 쓰지 않습니다. `backup.json`이 없는 폴더는 백업으로 보지 않고 일반 톤 폴더(`.mo`)로 읽습니다. 확인할 슬롯을 고르고 **장비에 적용**을 누르면 원래대로 돌아갑니다.
- 백업 폴더의 `.mo` 파일은 공식 에디터에서도 열 수 있습니다.

## 3-1. 다른 AI에게 톤 받기 → 끌어다 놓기 → 적용
톤 200개를 직접 만들지 않고, 다른 AI(ChatGPT·Claude·Gemini 등)에게 JSON 파일로 받아 바로 장비에 넣을 수 있습니다.
1. 저장소의 `prompts` 폴더에서 내 장비에 맞는 요청문(`GE150Pro_AI_프롬프트.txt` 또는 `GE150_AI_프롬프트.txt`)을 엽니다. 안의 `[곡 목록]`에 곡을 적은 뒤(한 줄에 `번호 아티스트 - 곡명`, 번호 = 뱅크 01~50) **전체를 그대로 복사**해 다른 AI에게 붙여 넣습니다.
2. AI가 준 JSON을 `tonepack.json`처럼 **파일로 저장**합니다. 한 번에 길면 `tonepack_01-25.json`, `tonepack_26-50.json`처럼 나눠 받아도 됩니다.
3. 프로그램 창에 **`.json` 파일을 끌어다 놓습니다.** 여러 파일을 한꺼번에 놓으면 하나로 합쳐집니다. 끌어다 놓는 대신 **톤 JSON 불러오기** 버튼으로 파일을 골라도 됩니다. (폴더를 끌어다 놓으면 지금까지처럼 톤 데이터 폴더로 열립니다.)
   - 장비에 표시될 이름은 JSON의 `name` **그대로**입니다(공백 포함 GE150 Pro 16자 이하·GE150 14자 이하, 영문·숫자·공백·키보드 기호만, 한글 불가). 슬롯 번호는 장비가 따로 보여 주므로 `name`에 넣지 않습니다. `.mo` 파일 이름은 `<슬롯> <name>.mo`입니다.
4. 프로그램이 JSON을 검사해서 `.mo`로 바꿉니다.
   - **오류가 하나라도 있으면** `.mo`를 만들지 않고 오류 목록 창(슬롯·모듈·노브·사유)을 보여 줍니다. 목록을 그대로 AI에게 보내 고쳐 달라고 하면 됩니다.
   - **경고만 있으면** 변환한 뒤 경고 목록을 보여 줍니다(빠진 모듈·노브를 기본값으로 채운 내용 등).
   - 변환은 먼저 임시 폴더(`….partial`)에 만들고 검사까지 통과해야 최종 이름으로 바꿉니다. 파일 쓰기 오류나 검사 실패가 나면 오류 목록을 보여 주고 임시 폴더를 지우므로, 반쯤 만들어진 폴더가 남지 않습니다.
   - 성공하면 JSON 파일이 있는 폴더에 `<JSON 이름>_mo_날짜-시간` 폴더가 만들어지고(이미 있는 폴더를 덮어쓰지 않습니다), 그 폴더가 곧바로 톤 데이터 폴더로 열려 표에 나타납니다. 이름이 `.partial`로 끝나는 폴더는 실패한 변환의 찌꺼기이므로 톤 폴더로 열 수 없습니다(안내가 나옵니다).
5. 표의 상태(변경·동일 등)를 확인하고 **장비에 적용**을 누릅니다(2절 5번과 같음). 엑셀로 보기의 `요약` 시트에는 곡·아티스트·역할도 함께 나옵니다.
- 변환 대상 기종은 연결된 장비 → 톤 JSON 의 `device` 값 → 두 기종 중 고르는 작은 창 순서로 정합니다. GE150 Pro 용 톤을 GE150 에 넣으면 GE150 에 없는 모델과 14자를 넘는 이름이 오류로 표시됩니다.
- 명령줄로 변환만 할 때: `python cli.py convert tonepack.json [--out 폴더] [--device GE150|GE150PRO]` (장비 연결 필요 없음).
- 명령줄로 장비(또는 백업)를 톤 JSON 으로 저장할 때: `python cli.py export-json 출력.json [--from-backup 백업폴더] [--songs 곡목록.txt] [--title 제목]`. `--from-backup` 을 주면 장비에 연결하지 않고 그 백업 폴더(기종은 `backup.json` 에서 읽음)만 읽습니다. 곡 목록은 한 줄에 `번호 아티스트 - 곡명`(번호 = 뱅크 01~50)이며, 주면 각 프리셋에 `song`·`artist`·`role`(CLEAN·CRUNCH·DRIVE·SOLO)이 들어갑니다. 출력 파일이 이미 있으면 덮어쓰지 않고 오류로 끝납니다.
- GE150 Pro 용 톤 JSON 을 GE150 용으로 바꿀 때: `python cli.py to-ge150 Pro톤.json --out GE150톤.json [--notes 내역.txt]` (장비 연결 필요 없음). GE150 에 없는 Pro 전용 모델을 비슷한 모델로 바꾸고 14자를 넘는 이름을 줄이며, 바뀐 내용을 화면에 보여 줍니다(`--notes` 를 주면 파일에도 저장). 소리는 Pro 와 달라질 수 있습니다. 모델 대응표는 [톤JSON_형식.md](톤JSON_형식.md)의 6절입니다. 변환 결과가 GE150 검사를 통과하지 못하면 종료 코드 1 로 끝납니다(예: 사용자 샘플 칸 EMPTY).
- 형식의 상세 규칙은 [톤JSON_형식.md](톤JSON_형식.md)입니다.

## 4. 그 밖의 기능
- **장비→.mo 저장**: 장비 200개를 원하는 폴더에 `01A 이름.mo` 형식으로 저장합니다.
- **장비→톤 JSON 저장**: 장비 200개를 [톤 JSON](톤JSON_형식.md) 파일 하나로 저장합니다(저장할 위치와 이름을 고릅니다). 나중에 이 파일을 끌어다 놓아 같은 상태로 되돌리거나, AI 에게 보여 주고 고쳐 달라고 할 수 있습니다. 사용자 샘플 칸(EMPTY)·PITCH 계열 모델처럼 다시 불러올 때 오류가 되는 내용은 파일에는 그대로 담고 저장 뒤 안내 창에 알려 줍니다.
- **엑셀로 보기**: 목록을 `.xlsx`로 만들어 엽니다(읽기용). `장비 내용`/`폴더 내용` 중 보고 싶은 쪽을 옆 선택 상자에서 고릅니다. 시트는 `요약`과 `톤 상세` 두 개입니다. 백업 폴더를 골랐을 때도 `톤 상세`에 복원할 원본 내용이 나오고, 해석할 수 없는 슬롯은 "해석 불가(원본 바이트 그대로 복원)"로 한 줄 표시됩니다.

## 5. 주의
- 적용 중에는 USB 케이블을 뽑거나 장비 전원을 끄지 마십시오.
- 백업 폴더는 프로그램(exe)이 있는 폴더의 `백업`에 만들어집니다. 오래된 백업은 직접 지워도 됩니다.
- 연습해 보려면 바로가기 대상 끝에 `--fake`(가짜 GE150 Pro) 또는 `--fake=ge150`(가짜 GE150)을 붙여 실행하면 장비 없이 가짜 장비로 동작합니다(실제 장비에는 아무 영향이 없습니다).

## 6. 아직 확정되지 않은 것
